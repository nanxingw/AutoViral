### A1 · Chat 稳定 block id 贯通：server 分配 → 落盘 → 三路 seed → 前端 by-id upsert

**What**：给每个 ChatBlock 发稳定身份，根治消息重复/闪回。server 在块进 messageHistory 时分配单调稳定 id（`{sessionId}:{seq}` 形态），chat 日志落盘带 id；HTTP history / WS history 重放 / WS 实时块三条 seed 路径全部携带同一 id；前端 store 改 Map+顺序数组的 by-id upsert，旧日志无 id 行按行号合成兜底 id（照 loadWorkChat 逐行归一先例），现有末块启发式仅留作旧 server 兼容 fallback。**并入 seed 收敛**：默认会话 history 读取改 jsonl-first（json 快照仅作旧数据分叉 fallback），消除 mid-turn 陈旧快照吞新块的竞态。

**预设测试**（先落盘证红）：
- `src/server/sessions/__tests__/ws-bridge-block-id.test.ts`：块 id 单调且稳定；三路 seed 载荷均含同一 id；重连 message_history 重放 id 与首次一致；旧 jsonl 无 id 行合成 `hist_{i}` 兜底。
- `src/domain/work-store` 相关测试：默认会话 jsonl-first；chat.json 仅在 jsonl 缺失时兜底（覆盖既有三个分叉 work 形态）。
- `web/src/features/chat/store.test.ts` 扩展：同 id 两次到达只渲染一条（含**非连续**重复——中间隔 tool_result）；setBlocks 全量替换与 push 实时块交错到达最终一致；无 id 块走末块启发式不回归。

**Acceptance criteria**：
- [ ] 预设测试先行落盘并证红，实现后全绿；既有 web/server 套件不破。
- [ ] 三条 seed 路径携带同一稳定 id（新增 StreamBlock 字段必须穿全部 seed 路径——历史 lesson 升级为回归测试）。
- [ ] 已落盘重复的历史 work（如 w_20260408_1347_db8）加载后按 id 去重展示，不再双泡。
- [ ] mid-turn 打开面板不再"闪回旧状态再跳回"。

**Blocked by**：None — can start immediately。
**Code-area hints**：`src/ws-bridge.ts`、`src/domain/work-store.ts`、`src/server/routes/works.ts`、`web/src/features/chat/`。
